# dotfiles (archived)

This repository has been restructured. All previous dotfiles, scripts, and configurations have been moved to the [`dots.bak/`](dots.bak/) directory.

## What changed?

The `dots.bak/` directory contains the old files including:

- `setup.sh` — Installation script
- `src/` — All configuration files (Zsh, Ghostty, bat, fastfetch, opencode, git)
- `tests/` — Test suite
- `.github/` — CI workflows
- `assets/`, `CHANGELOG`, `LICENSE`, `.gitignore`

## Quick Reference

The dotfiles project provided an automated macOS development environment setup using Homebrew, Zsh, and Ghostty. The original README and all source files are preserved in [`dots.bak/`](dots.bak/).
