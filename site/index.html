~ $ dots --features
── features ──
◆ Interactive TUI ratatui dashboard with 6 panes: symlinks, tools, plugins, configs, updates, network
◆ Symlink management Declare links in links.toml or use GNU Stow folding. Idempotent with backups
◆ Cross-platform installs One dep list per platform via Homebrew, apt, dnf; required/optional/dev tiers
◆ Premade configs Ghostty, Neovim, opencode starter configs compiled into the binary
◆ Network monitor Live pane: connectivity, latency, DNS, VPN status via platform probes
◆ Portable profiles Export to personal.json, re-import on another machine or from GitHub
